# StudyBot - AI Chatbot Web n8n

## Deskripsi
StudyBot adalah chatbot AI berbasis web yang dibuat menggunakan n8n.cloud dan Google Gemini. Chatbot ini dirancang untuk membantu mahasiswa dalam menjawab pertanyaan seputar perkuliahan dan kegiatan belajar.

## Teknologi
- n8n.cloud
- Google Gemini
- AI Agent
- Simple Memory
- Web Chat

## File Workflow
File JSON berisi workflow n8n untuk chatbot StudyBot.
